# Fine-Tuning CRRTnet

This directory contains the code and instructions needed to fine-tune the pretrained CRRTnet model using data from your center.

Before proceeding, complete all steps described in the preprocessing documentation. Fine-tuning requires the model input dataset generated by the preprocessing pipeline.

## Prerequisites

Before running fine-tuning, confirm that preprocessing has completed successfully.

The following files are required:

```text id="gfpkm4"
data/
├── outputs/
│   ├── transformed_features.csv
│   └── model_input.csv
└── models/
    └── best_model_mrmr_80feats_roc_auc.joblib
```

`model_input.csv` contains the model input features generated by the preprocessing pipeline.

`transformed_features.csv` is used to retrieve the Day 7 outcome (`DAY7_Outcome`) for each patient.

You must also have a copy of the pretrained CRRTnet model in `.joblib` format and placed within the `models/` folder.

## Fine-Tuning the Model

Run the fine-tuning script using:

```bash id="n2u0dg"
python src/finetune.py \
    --base-model-path data/models/best_model_mrmr_80feats_roc_auc.joblib \
    --output-predictions-filename <OUTPUT_PREDICTIONS_FILENAME>.csv
```

### Optional Arguments

The following optional arguments can be defined:

- `--seed`: Random seed used for data splitting and hyperparameter sampling. The default is `42`.
- `--n-iter-sampler`: Number of hyperparameter combinations evaluated during random search. The default is `50`.

For example:

```bash id="8bntjj"
python src/finetune.py \
    --base-model-path data/models/best_model_mrmr_80feats_roc_auc.joblib \
    --output-predictions-filename <OUTPUT_PREDICTIONS_FILENAME>.csv \
    --seed 42 \
    --n-iter-sampler 50
```

These default values were the ones used to pre-train on external datasets within the paper.

## Fine-Tuning Information

### Fine-Tuning Hyperparameters

The script uses Optuna to evaluate randomly sampled combinations of:
- number of additional trees;
- learning rate;
- maximum tree depth;
- minimum child weight;
- L2 regularization; and
- class-imbalance weighting.

## Outputs

After fine-tuning completes successfully, the following files are generated.

### Fine-Tuned Model

The fine-tuned CRRTnet model is saved to: `data/models/finetuned_model.joblib```

This file contains the center-specific fine-tuned model.

### Held-Out Predictions

Predictions for the held-out test partition are saved to:

```text id="63itb8"
data/outputs/<OUTPUT_PREDICTIONS_FILENAME>
```

For example:

```text id="n0kk05"
data/outputs/finetune_predictions.csv
```

The prediction file contains:

- `id`: patient identifier;
- `y_true`: observed Day 7 outcome;
- `pred`: binary model prediction using a threshold of 0.5; and
- `prob`: predicted probability of the outcome.

## Next Steps
Once fine-tuning has completed successfully, use the held-out predictions to evaluate the performance of the fine-tuned CRRTnet model at your center.
